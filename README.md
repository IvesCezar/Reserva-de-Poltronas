# 🎟️ Sistema de Reserva de Poltronas

Sistema web desenvolvido em **JavaScript** para realizar o gerenciamento e a reserva de poltronas. O projeto permite visualizar as poltronas disponíveis, selecionar lugares e realizar reservas de forma simples e intuitiva.

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web utilizando **JavaScript**, criando uma aplicação de reserva de poltronas.

A aplicação apresenta um mapa de assentos, permitindo que o usuário identifique quais poltronas estão **disponíveis**, **selecionadas** ou **reservadas**.

## 🚀 Funcionalidades

* 🪑 Visualização das poltronas disponíveis
* ✅ Seleção de poltronas
* 🔒 Identificação de poltronas já reservadas
* 💾 Registro das reservas
* 🔄 Atualização do status das poltronas
* 📱 Interface simples e intuitiva
* ⚡ Interações realizadas com JavaScript

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — estilização e layout
* **JavaScript** — lógica e interatividade




## 🎯 Como utilizar

1. Acesse a aplicação.
2. Visualize o mapa de poltronas.
3. Escolha uma poltrona disponível.
4. Confirme a reserva.
5. A poltrona reservada será identificada como indisponível para novas reservas.
